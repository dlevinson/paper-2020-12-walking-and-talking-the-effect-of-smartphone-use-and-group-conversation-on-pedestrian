# Restricted Source Workbooks

These workbooks are staged for private verification only. They contain exact observation timing and, for City Road, free-text visual descriptions of pedestrians. Do not publish this folder without a separate privacy/deidentification decision.

- `city_road_bridge_source_workbook.xlsx`: copied from the local `ped-data 2018-07-10.xlsx` workbook.
- `bay_street_source_workbook.xlsx`: copied from the local `Pedestrain walking speed 4.0.xlsx` workbook.

Use `../../code/create_deidentified_extracts.py` to regenerate the public candidate extracts.
