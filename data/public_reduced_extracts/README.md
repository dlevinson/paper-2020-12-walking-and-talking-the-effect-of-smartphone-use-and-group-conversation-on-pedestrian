# Public Reduced Extracts

These CSV files are compact extracts from the source workbooks. They support the paper-level claims while omitting workbook columns not needed for those checks, including exact entry/exit times, free-text descriptions/notes, and appearance/height/footwear columns.

- `city_road_bridge_observations_reduced.csv`: 180 observations.
- `bay_street_observations_reduced.csv`: 477 observations.
- `extract_summary.json`: row counts and filtering notes from the extraction script.
