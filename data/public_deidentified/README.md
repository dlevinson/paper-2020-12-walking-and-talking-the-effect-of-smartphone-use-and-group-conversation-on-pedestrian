# Public Candidate Deidentified Extracts

These CSV files are derived from the restricted source workbooks for release review. They are intended to support the paper-level claims without publishing exact raw observation times, free-text descriptions, notes, or body-measurement estimate columns.

- `city_road_bridge_observations_deidentified.csv`: 180 observations.
- `bay_street_observations_deidentified.csv`: 477 observations.
- `extract_summary.json`: row counts and filtering notes from the extraction script.
