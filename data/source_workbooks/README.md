# Source Workbooks

These are the two source analysis workbooks used to reproduce the observation counts and variables reported in the paper. A header review found public-place pedestrian observation variables, but no names, addresses, contact details, respondent IDs, GPS traces, licence plates, or household identifiers.

- `city_road_bridge_source_workbook.xlsx`: copied from the local `ped-data 2018-07-10.xlsx` workbook.
- `bay_street_source_workbook.xlsx`: copied from the local `Pedestrain walking speed 4.0.xlsx` workbook.

Use `../../code/create_reduced_extracts.py` to regenerate the compact CSV extracts.
